# 静配中心排班系统（新版）

用 Electron 22 + React + TypeScript 重写的排班工具，用来替代仓库根目录下的 MFC 版本。
Electron 22 是最后一个支持 Win7 的版本，所以版本号固定在 22.3.27，不要升级。

当前版本 0.2.0：导入、排班调整、规则检查、调休联动与还班、轮次滚动、导出、统计、备份都已可用，见下面“功能”。

## 常用命令

```bash
npm install          # 安装依赖
npm run dev          # 浏览器里调界面（数据存在浏览器 localStorage）
npm test             # 运行规则、方案查找、修改记录的单元测试
npm start            # 编译后用 Electron 打开
npm run dist:win     # 打 Windows 安装包和绿色版（32 位 + 64 位），输出到 release/
```

`dist:win` 需要在 Windows 上运行，或者在装了 wine 的 Linux/macOS 上运行。

**在 Windows 上打包最简单的办法**：装好 Node.js 后，双击 `打包.bat`。它会先 `npm install` 装依赖，再打包，完成后自动打开 `release` 文件夹：

- `静配中心排班系统 Setup 0.2.0.exe`：安装版（32 位和 64 位合在一个安装包里，安装时自动选）
- `静配中心排班系统 0.2.0.exe`：绿色版，双击就能运行，数据放在 exe 旁边的 `data` 文件夹

打包要在 Win10/11 上做，打出来的程序可以在 Win7 SP1 上运行。

如果手动运行命令，**第一次一定要先 `npm install`**，否则会报 “'tsc' 不是内部或外部命令”。

## 目录

```
electron/            主进程：窗口、读写数据文件、每日备份
src/domain/          数据结构和业务逻辑（不依赖界面，可单独测试）
  types.ts           人员 / 级别 / 班次 / 轮次 / 修改记录 的结构
  schedule.ts        当前排班 = 原始排班 + 未撤销的修改；格子修改链；撤销重做
  rules.ts           初版规则：级别权限、夜班后休息、3-4~3-7 上限、连班
  plans.ts           初版调休方案查找（1 步 / 2 步）
  seed.ts            第一次打开时的示例数据
src/import/          Excel 导入：读取文字和字体颜色、解析表头日期、识别班次、生成新的一轮
src/store/           界面状态和自动保存
src/components/      左侧导航、排班表、格子菜单、调休方案浮窗、修改历史、启动恢复
src/pages/           人员、班次、尚未开发模块的占位页
```

## 导入 Excel 排班表

- 第一次打开软件时会要求导入现有的 Excel 排班表；之后每次打开都直接用上次的数据和修改，不需要再导入。
- 只有拿到新一轮的表时，才在左侧“数据”里再导入一次：从新表开始新的一轮，之前的排班和修改记录都保留。
- 表格格式按现有模板：标题行、“人员\日期”+ 日期行（8.17…）、星期行、每人一行。年份按星期行自动对上，导入前可以改。
- 级别按姓名的字体颜色区分：黑色 = 技术员，红色 = 高级技术员，紫色 = 第三方；黑色但只上 A/B/C/D/T 的人算药师。导入前可以按颜色或逐个人调整。
- 格子内容：`3—1` 这类破折号、空格会自动纠正；`调休张`、`补五孙` 这类写法按调休 / 补五一处理，界面上仍显示原文；认不出的内容原样保留，并在导入前列出来。

## 数据保存

- 每次修改都会自动保存，不需要点“保存”。关窗口时还没写盘的修改会同步写完再关。
- 绿色版数据放在 exe 旁边的 `data/schedule-data.json`；装在没有写权限的目录时，放到用户目录。
- 每天第一次保存时在 `data/backups/` 留一份备份，保留最近 30 份。
- 所有改动都记成修改记录（ChangeSet），撤销只是给记录打上“已撤销”标记，不会删掉，所以每个格子的完整修改链都能查到。

## 功能

- **导入**：第一次打开时导入现有 Excel 排班表，按姓名颜色分级别；之后打开直接接着上次的排班和修改
- **排班表**：紧凑排列，按级别分组、班次分类配色；改过的格子整格上色（橙=手工改过，蓝=调休，红=被联动改班），最近一次操作加深色框；可只看改过的人。Ctrl +/- 缩放，F11 全屏
- **点格子**：看修改链；调休 / 补休 / 节日补休；换班次（违反拦截规则的置灰并写原因，只提示的标橙点）；自定义内容；删除班次
- **规则检查**：违规（红角）和提示（橙角）标在格子上，工具栏显示数量，点开列表可定位；改班时只拦截这次新增的问题；跨轮回看上一轮最后 7 天
- **调休联动**：最多 4 人的联动方案，按步数 → 级别优先（级别3 > 级别1 > 级别2，级别4 > 级别2）→ 班次类型排序；浮窗不遮暗背景、可拖动，表格里虚线预览变动
- **还班**：3-4 / 3-5 / 3-7 调休时给出还班日期，或先记为待还班；“调休申请记录”里汇总
- **修改历史**：每条修改可追溯、可撤销 / 重做；单个格子的完整修改链
- **轮次**：‹ › 切换各轮；按“班不动、人滚动”生成下一轮（不轮班 / 冻结的人不动，调休变空白格）
- **导出 Excel**：和导入模板同格式，可再导入；可给改过的格子上底色；附修改记录表
- **统计**：每人上班、休息、调休、夜班、帮夜、A、T、3-4~3-7、被改动次数和规则问题
- **规则**：每条规则可开关、改参数、设“拦截”或“只提示”
- **班次 / 人员**：级别权限矩阵、自定义班次；人员级别、状态（在岗 / 不轮班 / 冻结）、只上 / 不上某些班、新增、调整顺序
- **数据**：每日自动备份、恢复到某天、导出 / 导入整份数据文件
- **设置**：操作人（记入修改记录）

## 已知限制

- 打包需在 Win10/11 上进行；Win7 上只能运行，没有真机验证过，首次部署请先试装
- “3-4、3-5、3-7 每天总数限制”需求里没有给出具体数字，暂未做成规则；可在“规则”页按“每日人数”的方式自行添加后再完善
- 待还班需要在排班表里手工安排
